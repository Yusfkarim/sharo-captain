# شاڕۆ کاپتن | Sharo Captain App
**ناسێنەری پاکێج (Bundle ID):** `com.sharo.captain`  
**فرەیمۆڕک:** Flutter 3.24.5 / Dart 3.5.4  
**مۆڵەت (License):** MIT License

ئەپڵیکەیشنی فەرمی شۆفێر و کاپتنەکانی تۆڕی **شاڕۆ (Sharo)** بۆ گەیاندنی لۆجستیك و داواکارییەکان لە چێشتخانە و مارکێتەکانەوە بۆ دەستی کڕیاران لە سلێمانی.

---

## تایبەتمەندییە سەرەکییەکان
- **دۆخی ئۆنلاین / ئۆفلاین (Online / Offline Toggle):** دیاریکردنی کاتی کارکردنی کاپتن و ناردنی شوێنی ڕاستەقینە بۆ سێرڤەر.
- **ڕاداری وەرگرتنی داواکاری لە کلاود:** پشکنینی ڕاستەوخۆی سێرڤەر بۆ بەردەستبوونی خواردنی ئامادەکراو لە نزیکترین چێشتخانە.
- **پرۆسەی هەنگاو بە هەنگاوی گەیاندن:**
  1. وەرگرتنی داواکاری و بەڕێکەوتن بەرەو چێشتخانە.
  2. گەیشتن بە چێشتخانە و وەرگرتنی پاکێج (Pick Up Order).
  3. دەستپێکردنی ڕێگای کڕیار بە دوگمەی پەیوەندی تەلەفۆن.
  4. ڕادەستکردنی خواردن و تۆمارکردنی بڕی پارەی کاش لە سیستەم.
- **جزدانی داهاتی کاپتن (Captain Wallet):**
  - پیشاندانی کۆی داهاتی ڕۆژانەی گەیاندنەکان بە دیناری عێراقی.
  - ژماردنی پارەی کاشی ناو دەستی کڕیاران بۆ ڕادەستکردنەوە.
  - مێژووی تەواوی گەشتە سەرکەوتووەکانی ئەمرۆ.

---
